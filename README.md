# 局域网文件共享工具

把本地一个文件夹共享到局域网，其他人用浏览器打开网页即可查看文件列表并下载，支持一键生成**带密码的分享链接**发给指定的人。

支持双角色密码：**访问密码**（普通用户，只能看列表和下载）和**管理员密码**（额外拥有一个设置页面，可随时修改分享目录、访问密码、管理员密码、分享功能开关）。

## 下载即用（推荐）

从 [GitHub Releases](https://github.com/ikunfami/file-share-server/releases) 下载最新的 `fileShare.x.x.x.exe`，放到任意目录**双击运行**即可，无需安装 Python。

## 环境要求（源码运行）

- Python 3.8+（Windows 上用 `py` 命令，或把下文的 `py` 换成 `python`）
- 依赖：

```bash
py -m pip install -r requirements.txt
```

## 启动

```bash
py share.py
```

**首次运行**会自动完成初始化：

- 在桌面创建「分享文件夹」（内含使用说明文档），并设为默认分享目录
- 生成配置文件 `config.toml`，端口 8000
- 默认密码 —— 访问密码 `123456`（**默认关闭**，可在设置页启用）、管理员密码 `admin456`（建议尽快在设置页修改）

配置位置分两种模式：**脚本直接运行**读项目根目录的 `config.toml`；**exe 运行**读 `%APPDATA%\file-share-server\config.toml`（exe 目录保持干净）。

启动后控制台会打印访问地址与运行状态，例如：

```
版本：v1.0.4
共享目录：D:\共享文件夹
本机访问：http://127.0.0.1:8000
局域网访问：http://192.168.1.5:8000
访问密码：未开启
管理员密码：已设置
分享功能：已开启
```

局域网内其他电脑/手机用浏览器打开「局域网访问」那个地址即可。按 `Ctrl+C` 停止服务。

## 两种密码

| 密码 | 作用 |
|------|------|
| **访问密码** | 普通用户登录后只能浏览文件列表、下载文件；关闭后所有人免登录浏览 |
| **管理员密码** | 拥有普通用户全部权限，额外可打开「⚙️ 设置」页面 |

登录页只提供一个密码框，输入哪个密码就自动获得对应角色权限。访问密码关闭时，匿名用户首页右上角提供「管理员登录」入口。

## 分享功能

- 文件列表每行有「分享」按钮（在「下载」左侧），点击后链接**自动复制到剪贴板**并弹窗提醒
- 分享链接格式：`http://地址/s/文件路径?pwd=访问密码`（访问密码关闭时不带 `pwd`）
- 打开链接：密码正确 → 文件自动下载；密码错误 → 提示并可重试；文件不存在 → 明确提示
- 链接中的密码每次访问都严格校验，改密码后旧链接立即失效
- 可在设置页**整体关闭分享功能**（默认开启），关闭后列表不再显示分享按钮、已发出的链接全部失效

## 设置页面（管理员）

管理员登录后，文件列表右上角有「⚙️ 设置」入口，可以：

- **分享目录**：修改共享的文件夹路径（支持「选择目录」从系统对话框挑选），保存后立即生效
- **访问密码**：启用/关闭、设置新访问密码（默认关闭）
- **分享功能**：启用/关闭分享按钮与分享链接（默认开启）
- **管理员密码**：设置新管理员密码

密码框留空表示不修改该项。修改密码后其他已登录会话会全部失效（当前管理员保持登录）。密码以明文保存在 `config.toml` 中（用于登录校验和生成分享链接），请妥善保管该文件，勿提交到公开仓库。

## 命令行参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--dir` | 设置要共享的文件夹 | `py share.py --dir D:\资料` |
| `--port` | 设置端口（默认 8000） | `py share.py --port 8080` |
| `--password` | 设置访问密码并开启访问保护 | `py share.py --password 123456` |
| `--admin-password` | 设置管理员密码 | `py share.py --admin-password admin123` |
| `--no-password` | 关闭访问密码保护 | `py share.py --no-password` |
| `--no-browser` | 启动后不自动打开浏览器 | `py share.py --no-browser` |
| `--no-minimize` | 启动后不自动最小化窗口（仅 exe） | `py share.py --no-minimize` |

启动后默认会自动用系统默认浏览器打开**局域网访问地址**（无局域网 IP 时打开本机地址），加 `--no-browser` 可关闭。exe 运行时控制台窗口会自动最小化到任务栏（不影响服务运行），加 `--no-minimize` 可关闭。

## 系统托盘（exe）

exe 运行时任务栏通知区域会有托盘图标（应用图标），**右键菜单**三个项：

- **打开**：用浏览器打开访问页面（双击图标同效）
- **查看**：唤出控制台窗口查看访问日志
- **退出**：停止服务并退出程序

启用托盘后，点窗口的 X 只是隐藏窗口**不会退出服务**，只能通过托盘「退出」结束程序。加 `--no-tray` 可禁用托盘（此时 X 为正常关闭）。

所有参数都会自动保存到配置文件，之后直接运行即可按上次配置启动。也可以直接编辑该文件。

## 网页端功能

- 文件列表：文件名、大小、修改时间，文件夹可点击进入，带面包屑导航
- 下载：每个文件后有「下载」按钮；文件夹没有下载/分享操作
- 页脚显示当前版本号

## 其他

- 控制台会记录访问日志（每个访客按 IP 只记第一次访问）
- 生产级 waitress 服务器，无开发警告

## 安全说明

- 路径经过校验，无法通过 `..` 访问共享目录之外的文件
- 设置页面仅管理员可访问
- 仅建议在内网/可信网络中使用
