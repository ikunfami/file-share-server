# 局域网文件共享工具

把本地一个文件夹共享到局域网，其他人用浏览器打开网页即可查看文件列表并下载。

支持双角色密码：**访问密码**（普通用户，只能看列表和下载）和**管理员密码**（额外拥有一个设置页面，可随时修改分享目录、访问密码、管理员密码）。

## 环境要求

- Python 3.8+（Windows 上用 `py` 命令，或把下文的 `py` 换成 `python`）
- 依赖：Flask

```bash
py -m pip install -r requirements.txt
```

## 启动

```bash
py share.py
```

**首次运行**会自动完成初始化：

- 在桌面创建「分享文件夹」（内含使用说明文档），并设为默认分享目录
- 生成配置文件：端口 8000，默认开启密码保护
- 配置保存在系统目录 `%APPDATA%\file-share-server\config.toml`（软件/exe 目录保持干净，不生成任何文件）
- 默认密码 —— 访问密码 `123456`，管理员密码 `admin456`（建议尽快在设置页修改）

启动后控制台会打印访问地址，例如：

```
共享目录：D:\共享文件夹
本机访问：http://127.0.0.1:8000
局域网访问：http://192.168.1.5:8000
```

局域网内其他电脑/手机用浏览器打开「局域网访问」那个地址即可。按 `Ctrl+C` 停止服务。

## 两种密码

| 密码 | 作用 |
|------|------|
| **访问密码** | 普通用户登录后只能浏览文件列表、下载文件 |
| **管理员密码** | 拥有普通用户全部权限，额外可打开「⚙️ 设置」页面 |

登录页只提供一个密码框，输入哪个密码就自动获得对应角色权限。

## 设置页面（管理员）

管理员登录后，文件列表右上角有「⚙️ 设置」入口，可以：

- **分享目录**：修改共享的文件夹路径，保存后立即生效
- **访问密码**：启用/关闭访问密码、设置新访问密码
- **管理员密码**：设置新管理员密码

密码框留空表示不修改该项。所有密码均以 SHA-256 哈希存储在 `config.toml` 中，不明文保存。

## 命令行参数

| 参数 | 说明 | 示例 |
|------|------|------|
| `--dir` | 设置要共享的文件夹 | `py share.py --dir D:\资料` |
| `--port` | 设置端口（默认 8000） | `py share.py --port 8080` |
| `--password` | 设置访问密码并开启访问保护 | `py share.py --password 123456` |
| `--admin-password` | 设置管理员密码 | `py share.py --admin-password admin123` |
| `--no-password` | 关闭访问密码保护 | `py share.py --no-password` |

示例：共享 D 盘的「照片」文件夹，端口 9000：

```bash
py share.py --dir D:\照片 --port 9000 --password 123456 --admin-password admin123
```

所有参数都会自动保存到 `%APPDATA%\file-share-server\config.toml`，之后直接运行 `py share.py` 即可按上次配置启动。也可以直接编辑该文件。

## 网页端功能

- 文件列表：文件名、大小、修改时间，文件夹可点击进入，带面包屑导航
- 下载：每个文件后有「下载」按钮
- 密码保护开启时，访问任何页面都会先进入登录页

## 安全说明

- 路径经过校验，无法通过 `..` 访问共享目录之外的文件
- 访问者无法访问设置页面（强制跳转/403）
- 仅建议在内网/可信网络中使用
